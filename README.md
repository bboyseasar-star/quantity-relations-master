# 👹 高校入試対策シリーズ ～大問2・割合・数量関係～

沖縄県立高校入試で確認した出題形式だけを使い、問題文・数値・文脈・解説を独自生成する10問の静的Webアプリです。過去問本文は転載していません。

- 10問、9問以上でクリア
- 数量計算A 5問、関係表現B 4問、転移1問
- 3段階ヒント。第3段階はギブアップとして正答と解説を表示
- 問題画面で使える手書きメモ（ペン・部分消し・全消し）。画面切替時に自動消去し、保存・送信はしません
- 結果後に、誤答した形式の別数値問題だけを全問正解まで復習可能
- 通常履歴（最大20件）、最高得点、直前の誤答形式メタデータを端末内のlocalStorageに保存。答案本文と復習結果は保存しません
- ローカル確認は静的サーバーから`index.html`を開いてください

数式表示・数式入力・Webフォントの読込時には外部CDNへ通常のアクセス情報が送信されます。接続先は`DEPENDENCIES.md`に記載しています。学習履歴や答案を送る独自通信はありません。

このアプリは沖縄県および沖縄県教育委員会の公式アプリではありません。公開・配布時の条件と第三者依存は`NOTICE.md`、`LICENSE`、`DEPENDENCIES.md`を確認してください。
